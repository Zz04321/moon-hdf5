# Code audit — 2026-10-19

Static review covered framing, navigation, metadata and decoding. Counterexamples
were generated with h5py 3.16.0/NumPy 2.5.4 and run through the native inspector.
This is not an exhaustive conformance or fuzzing audit. All six listed findings
were subsequently fixed and covered by regression tests.

| Priority | Evidence | Finding and next action |
| --- | --- | --- |
| Fixed | Regression tested | Nonstandard integer precision/offset and floating-point fields now raise `UnsupportedFeature`. Standard integer widths and IEEE floats retain both byte orders. Dataset and attribute decoding share this validation. |
| Fixed | Regression tested / CLI verified | Attribute-info heap/index addresses now distinguish dense from compact storage. Compact tracked attributes read normally; dense attributes raise `UnsupportedFeature`. CLI displays attribute-read errors with their object path. |
| Fixed | Regression tested | Dataspace/chunk products now check limits before multiplication. Dataset byte sizes are bounded before reading/allocating storage, and chunk copies validate byte capacity before narrowing offsets. Zero-dimensional arrays remain empty regardless of dimension order. |
| Fixed | Regression tested | V2 continuation parsing included the checksum in the message region, so a short trailing gap caused a bogus message and EOF. Parsing now excludes signature/checksum, uses the correct prefix size with creation-order tracking, and checks complete chunk bounds before reading. |
| Fixed | Regression tested | Unallocated contiguous storage now returns default/custom fills; empty/null data does not dereference addresses. Allocated data remains unchanged; external storage and disabled fills are explicitly rejected when applicable. |
| Fixed | Regression tested / process verified | CLI errors now go to stderr and return 1; usage errors return 2, successful reads return 0. Dataset and attribute failures affect the overall exit status without suppressing other dataset output. |

P1 denotes incorrect or potentially unchecked results; P2 denotes compatibility
or error-reporting defects. Closing these findings does not establish full
format conformance; metadata checksums and out-of-scope structures remain.

## Reproduction inputs

Generate with h5py, then run `moon run src/cmd/main --target native -- <file.h5>`:

- Numeric offset: copy `h5py.h5t.STD_I32LE`, set precision 16 and offset 8,
  create a one-element dataset with the low-level API and write an int32 `[42]`.
  h5py reads `[42]`.
- Dense attributes: open with `libver=('v108', 'v108')`, create `value=[42]`
  with `track_order=False`, add scalar attributes `attr_0` through `attr_11`.
- Object header: with those bounds, create root datasets `signed`, `big_endian`,
  `floating`, `text`, `unallocated`, `default`, `partial_default`, in that order,
  each containing `[42]`.
- Contiguous fill: create `value` with `shape=(3,)`, `dtype='<i4'`,
  `fillvalue=-7`, no chunking, and do not write data.

Numeric and attribute regressions are generated by
`scripts/generate_metadata_fixtures.py` and covered by `src/metadata_wbtest.mbt`.
Arithmetic boundaries are covered by `src/size_wbtest.mbt` without large allocations.
Header regressions are generated by `scripts/generate_header_fixtures.py` and
covered by `src/object_header_wbtest.mbt`, including synthetic gap/truncation cases.
Contiguous fill regressions are generated by
`scripts/generate_contiguous_fixtures.py`; CLI cases are in `src/cmd/main/main_wbtest.mbt`.

## Follow-up review

Reviewed chunk-index readers, filter decoding, heap access and string decoding.
Shared chunk-size checks, stored-chunk reads and variable-width integers now use
common helpers without changing the public API. Format-specific index traversal
remains separate.

Fixed and covered by `src/audit_wbtest.mbt`:

- Vlen string lengths above Int32 range could wrap negative and reach an invalid
  slice unwrap. They are rejected before narrowing.
- Local heap lengths could truncate on conversion; segment bounds were unchecked
  before unsafe string scanning. Both parsing and public heap access now validate
  the segment.
- Global heap reads could return an object from a truncated declared collection,
  or return before validating its padding. Both bounds are now required.
- Manually constructed B-tree configuration could overflow the merge threshold
  multiplication. Thresholds are bounded before arithmetic.

This review does not establish complete malformed-input safety. Metadata checksum
verification, fuzzing and wider interoperability testing remain outstanding.
